# Physical results

No physical runs are included in this pilot-kit release. Synthetic software fixtures are not benchmark results.

Submit a real run using the repository issue form and the review procedure in CONTRIBUTING.md. Preserve failed missions and rejected records with their actual status.

A future results table should include: run ID, rules commit, model/version, operation, procurement, elapsed time, seed, qualifying recovered height, observed peak, cleared revenue, economic/build spend, final cash, usage disclosure and review reference. Group comparisons by matching conditions. Only a documented human evidence review may label a result verified.
